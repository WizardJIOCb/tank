# tank.rodion.pro

Проект создан для теста `codex.rodion.pro`.

Это небольшая браузерная многопользовательская танковая арена. Клиентская часть
работает на Vite, Three.js и Socket.IO, серверная часть использует Express и
Socket.IO для лобби, сессий игроков и синхронизации состояния боя.

## Возможности

- создание и список открытых боев;
- подключение нескольких игроков к одному бою;
- управление танком с клавиатуры и мыши;
- стрельба, попадания, счет и повторное появление игрока;
- сборка статического клиента для production-запуска.

## Команды

```bash
npm install
npm run dev
npm run build
npm start
```

По умолчанию dev-сервер запускается на `http://localhost:3000`.
